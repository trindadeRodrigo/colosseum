# Archive: do not run

The four scripts here sent the first mainnet transactions on Sep 30, 2026, from the demo wallet. They are kept as a record of how those transactions were built. Their evidence, with signatures, is in `docs/structurer/STATE.md` and `docs/GATES.md`.

They can spend real money and nothing calls them. Do not run them, and do not copy from them: the vault work replaces the token approval they rely on.
